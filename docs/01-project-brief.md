# 01. Project brief

## Goal

Build a complete documentary website with code (HTML, CSS and JavaScript) for the JOUR 652 Web Design class. The film used in the class is a documentary about Candomblé. The same structure will later be reused for the thesis documentary about Lake Tahoe, changing only the videos, photos and text.

## The film

- **Title:** Candomblé, Roots of Fate
- **Tagline (written for the site):** Two terreiros. One faith. Roots that refuse to be erased.
- **Runtime:** 14 minutes
- **Year filmed:** 2024
- **Director and editor:** Yasmin Barbosa
- **Locations:** a terreiro on an island in Salvador, Bahia, and a terreiro in Itaquera, a favela in the East Zone of São Paulo
- **People in the film:** Miguel Rosas, Júnior and followers of both terreiros
- **Angle:** shows how the religion is practiced in each place. In Bahia it is lived more peacefully. In São Paulo there is more persecution. The film shows dances and the game of búzios. The main character is Candomblé itself, and the film also addresses religious intolerance.

## Requirements given for the site

- Written entirely in English
- Hosted on GitHub and built with code
- Very visual and interactive
- Opens with a video, with many photos and a lot of information
- Contains everything a documentary website needs
- Built so that only the media and text change for the thesis
- Colors from nature (blue, green, brown) with a vibrant mood

## Working method

Step by step, in conversation. Claude asks questions, Yasmin answers and sends media and example sites, and each step is documented in this folder.
