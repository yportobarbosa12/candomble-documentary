# Project documentation

This folder records every step of building the website for *Candomblé, Roots of Fate*, so the process can be repeated for the Lake Tahoe thesis documentary.

| File | What it covers |
|---|---|
| [01-project-brief.md](01-project-brief.md) | The goal, the film, the audience and the requirements |
| [02-github-setup.md](02-github-setup.md) | How GitHub and GitHub Pages were connected, step by step |
| [03-design-decisions.md](03-design-decisions.md) | Inspiration sites, palette, fonts, layout choices |
| [04-code-walkthrough.md](04-code-walkthrough.md) | What each file and each section of the code does |
| [05-content-and-media-checklist.md](05-content-and-media-checklist.md) | Every text, photo and video still needed |
| [06-thesis-reuse-guide.md](06-thesis-reuse-guide.md) | How to turn this site into the Lake Tahoe documentary site |
| [CHANGELOG.md](CHANGELOG.md) | Dated list of every change |
| [screenshots/](screenshots/) | Images of each version of the site |

## Rule for future steps

Every time the site changes, add a line to `CHANGELOG.md`, update the file in this folder that is affected, and save a new screenshot in `screenshots/` named with the version, for example `v2-desktop-hero.jpg`.
